# Real Time Emotion Detection

This project uses Deep Learning and OpenCV to detect human emotions from facial expressions.

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Jupyter Notebook

## Files
- Detection.ipynb
- emotion_detection_model.h5
- haarcascade_frontalface_default.xml
- EmotionZip.ipynb

## Features
- Face detection using Haar Cascade
- Emotion classification using a trained deep learning model
- Real-time emotion prediction
